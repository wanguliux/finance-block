# 03 · 七个代码块的全部参数

插入方式：命令面板「插入代码块」或 Ribbon 的「插入代码块」图标，或在笔记里手打 ` ```块名 `。以下为各块参数（**视图块参数全部选填，留空走默认**）。

## 1. `fin-beancount` — 复式记账分录（真源，非视图）

| 参数 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `date` | 日期 | date | 是 | 默认今天（`autoToday`） |
| `txnType` | 交易类型 | select | 否 | 从 `finance-config.json` 的 `transactionTypes` 取（兜底词表：餐饮/交通/购物…） |
| `owner` | 归属 | select | 否 | 自己/家庭，默认"自己" |
| `narration` | 摘要 | text | 否 | 备注 |
| `legs` | 复式分录 | legs | 是 | N 腿动态编辑器：每腿选账户+填正数金额，符号由账户类别推导；「一键补平」自动补齐差额 |

> 这是唯一会写数据的块。语法见 `02-fin-beancount-syntax.md`。

## 2. `finance-log` — 流水视图

| 参数 | 标签 | 类型 | 说明 |
|------|------|------|------|
| `date` | 起始日期 | date | 从哪天往前查，默认今天。**不** autoToday（留空=每天滚动看最近 N 天） |
| `day` | 天数 | number | 起始日往前 N 天（含），默认 30；1=只看当天；0=不限 |
| `amount` | 金额范围 | amount | 引导式：先选运算符(大于/≥/小于/≤/之间/等于)再填元，**不做元→分换算** |
| `account` | 账户 | select | 任一分录命中即算，留空=全部 |
| `type` | 交易类型 | select | 留空=全部 |
| `owner` | 归属维度 | select | 留空=全部 |
| `id` | 账目 ID | text | 按 `^t-` 块引用精确查单笔（多个用 `;` 分隔；填了忽略日期范围） |

示例（看最近 7 天、餐饮分类）：
````
```finance-log
day: 7
type: 餐饮
```
````

## 3. `finance-ficalc` — 现金流模拟器（原 finance-fi 已并入）

| 参数 | 标签 | 默认 | 说明 |
|------|------|------|------|
| `rate` | 年利率 % | 4 | 年化收益率 |
| `startAge` | 起始年龄 | — | 图表 x 轴起点；早于当前年龄时从记账数据提取历史净资产 |
| `age` | 当前年龄 | 30 | 开始模拟的年龄（设了生日可留空自动推导） |
| `retireAge` | 退休年龄 | 60 | 停止积累、开始支取的年纪 |
| `principal` | 生息本金（万） | 100 | 可用于退休支取的生息资产本金 |
| `spend` | 年花费（万） | 4 | 每年花费 |
| `save` | 年净储蓄（万） | 10 | 每年净结余 |
| `incomeGrowth` | 储蓄增长 % | 3 | 积累期年净储蓄年增速 |
| `cashRate` | 现金收益率 % | 1.5 | 现金类资产年化收益 |
| `bufferMonths` | 应急金月数 | 6 | 预留 N 月支出作应急金（仅资产模式生效） |
| `infl` | 通胀率 % | 2 | 年通胀 |
| `years` | 预测年限 | 30 | 退休后预测多少年（默认自动至 95 岁） |
| `vol` | 波动率 % | 12 | 年化收益波动（0=确定性模拟） |
| `mode` | 提取策略 | — | `fixed` 恒定金额 / `percent` 固定比例 / `rule95` 95% 法则 |

> 数据源（actual=账本 / manual=手填 / assets=资产账户）由插件按是否配置资产账户**自动切换**，不是块参数。配置资产账户后自动分桶预填本金/年花费/年储蓄，拖滑条即可覆盖。引擎口径见 `08-engine-reference.md`。

## 4. `finance-budget` — 预算执行

| 参数 | 标签 | 类型 | 说明 |
|------|------|------|------|
| `type` | 交易类型 | select | 筛选某分类的预算计划，留空显示全部 |

> 预算计划在设置页「预算管理」里按 `transactionTypes` 设定支出上限（日/周/月/年/自定义 N 日）。

## 5. `finance-heatmap` — 收支热力图

| 参数 | 标签 | 默认 | 说明 |
|------|------|------|------|
| `day` | 天数 | 182 | 显示最近 N 天（7–365） |
| `view` | 默认视图 | calendar | `calendar` 总览日历（日粒度）/ `matrix` 分类矩阵 |
| `gran` | 矩阵粒度 | week | 矩阵列粒度：按周/按月（仅 matrix 生效） |
| `category` | 分类筛选 | — | 只看某分类，留空=全部 |

> 绿=净收入、红=净支出、空=无收支。

## 6. `finance-assets` — 资产总览

| 参数 | 标签 | 默认 | 说明 |
|------|------|------|------|
| `owner` | 归属 | — | 按归属筛选，留空=合并全部 |
| `group` | 分组方式 | class | `class` 按资产/负债分组 / `prefix` 按账户名前缀分组 |

> 展示净资产（市值口径）+ 结构 + 逐卡估值 + 负债 + 资产走势。估值来自账本内 `custom "fb-valuation"`。

## 7. `finance-recurring` — 日常花费 + 贷款（无参数）

界面三块：**今日待入账**（每天自动出的草稿，一键/批量入账或跳过）、**我的计划**（日常花费 V1）、**我的贷款**（贷款 V2，每期 3 腿由还款引擎生成）。计划/贷款在弹窗里建（见 `04-commands-and-modals.md`）。
