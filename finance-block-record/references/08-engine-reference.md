# 08 · 引擎口径（看懂视图数字从哪来）

## fiCalc — 财务自由 / 现金流模拟（finance-ficalc）

纯函数，不依赖 vault。所有金额内部以**分**计，界面向「万」展示。

**核心公式**（r = 年利率/100，P = 本金，S = 年花费）：
- 是否自由：`S <= P · r`（被动收益覆盖年花费）
- 所需本金：`P* = S / r`（r≤0 时无穷大）
- 本金缺口：`P* − P`（已自由则为负）
- 可持续年花费上限：`S* = P · r`
- 当前本金能撑几年（未自由）：`n = ln(S / (S − P·r)) / ln(1 + r)`；已自由 = ∞

**数据源（自动切换，非块参数）**：
- `actual`（实际/账本）：本金/年花费/年储蓄由账本派生——年花费取**近 12 个月实际年化花费**（`calculateActualSpend`，数据不足会标"仅 N 个月"）。
- `manual`（模拟）：参数全手填的 what-if 沙盒。
- `assets`（资产账户）：配置了资产账户后自动分桶预填，拖滑条可覆盖。

**提取策略（退休后本金耗尽前的年提取方式）**：
- `fixed` 恒定金额：每年取固定额，直到本金见底。
- `percent` 固定比例：每年取当前本金的固定比例，随市场浮动。
- `rule95` 95% 法则：取「当前本金比例」与「去年提取额×95%」的较大值。

**蒙特卡洛模拟**：`vol`（波动率）>0 时展开成功率与 P10/P50/P90 分位走势（`runs` 次模拟 × `years` 年）。

**双段生命周期图**：x 轴从 `startAge` 起；`startAge < age`（当前年龄）时左段显示**历史净资产**（由已入账交易按账户类别累加），右段为模拟。当前年龄由生日推导或 `age` 参数。

## Loan — 还款引擎（finance-recurring 贷款 V2）

三种方式（每期 3 腿：出资资产 / 负债 / 利息费用）：
- `annuity` 等额本息：每期总额固定，本金递增、利息递减。
- `equal-principal` 等额本金：每期本金固定，利息递减，总额递减。
- `interest-first` 先息后本：先只还息，末期一次性还本。

约束：尾差归末期；**续算**——起算本金 = `remainingPrincipal ?? (principal − 已入账本金累计)`，起始期号 = max(已入账期号)+1。视图「剩余本金」= 下一未入账期「期前剩余」。

> 贷款不支持跳过/改金额（破坏 schedule 期号连续链）；特殊操作走「编辑贷款续算」（改 `remainingPrincipal`）。

## fx — 跨币种换算

`convertToBase(amount, currency)`：金额 × 该币种 `rate`（相对默认币种）。账户/交易带币种后缀时，按 `finance-config.json` 的 `currencies[].rate` 折算到 `baseCurrency` 参与汇总。默认币种 rate=1。

## networth — 净资产（finance-assets）

`净资产 = 总资产 − 总负债`（结构不变量）。两口径：
- **账面(book)**：账户价值 = 账本流水累加。
- **市值(market)**：market 账户价值 = 账本内 `custom "fb-valuation"` 估值行覆盖（book 账户忽略估值）。

未实现损益 = 市值 − 账面；负债变化（如房贷）抵减净资产。草稿块内估值不计入。

## recurring — 日常花费派生（finance-recurring V1）

`recurringPlans[]` 每期固定金额 2 腿（支出+出资）；`recurringSkips` 记录跳过（按应发生日）。视图「今日待入账」= 今天应发生且未入账且未跳过的草稿，虚派生、不落盘；点「入账」才写账本并标 `plan: <id>`。已入账识别靠账本分录的 `plan` + `plan-date` 元数据。
