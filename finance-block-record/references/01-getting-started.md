# 01 · 快速上手与数据模型

## finance-block 是什么

Obsidian 里的**个人财务 OS**：以 `fin-beancount` 代码块为**唯一真源**做复式记账，其余 6 个代码块是只读派生视图（流水 / 预算 / 热力图 / 现金流模拟 / 资产总览 / 日常花费与贷款）。数据全是 vault 内的纯文本，可双链、可进 Git。

## 文件布局（默认）

```
vault/
├── finance-config.json      ← 配置（账户/币种/类型/预算/事件/计划/贷款）
└── 账本/账本.md              ← 账本（含唯一的 ```fin-beancount 块）
```

两条路径都在**设置页**可改（`ledgerPath` / `configPath`，默认值见 `06-settings.md`）。

## 核心数据模型

| 概念 | 说明 |
|------|------|
| **账户（AccountDef）** | 金融账户的「分类容器」，分五大类之一（资产/负债/权益/收入/费用）。**账户本身不存金额**——价值完全由账本流水累加（账面 `book`）或账本内估值行覆盖（市值 `market`）。 |
| **交易类型（TransactionTypeDef）** | 收支分类标签（如 餐饮/工资），带 `direction`（收入/支出）与可选自定义字段。**不是**账户，是查询/预算/热力图的筛选维度。 |
| **归属（Owner）** | 交易归属维度，预设 {自己, 家庭}，可自定义（默认"自己"）。 |
| **币种（CurrencyDef）** | ISO 代码 + 相对默认币种的汇率（默认币种 rate=1）。 |
| **分录（Leg）** | 一笔交易里的一个方向：账户 + 整数分金额（正=增加）。一笔交易所有 leg 之和必须为零。 |
| **估值（Valuation）** | `custom "fb-valuation"` 指令行，给市值计价账户打公允价值快照；不参与零和、不改余额，仅视图层覆盖。 |

## 五大类（Chart of Accounts，结构不变量）

账户必须归属其一，使「净资产 = 资产 − 负债」恒成立：

- **资产 asset**：现金、银行卡、股票、房产、车…
- **负债 liability**：房贷、车贷…
- **权益 equity**：结转专用（余额承接）
- **收入 income**：工资、奖金…（流量，记完归零）
- **费用 expense**：日常、餐饮…（流量，记完归零）

> 记账时**借贷符号由账户类别推导**（见 `02-fin-beancount-syntax.md` 与 `07-nl-recording.md`），界面不出现 +/-。

## 首次配置清单

1. 装好插件，打开设置页（默认已写入 `finance-config.json`，种子态见 `05-config-reference.md`）。
2. 在「账户」管理里按需增删账户（默认已给每类一个：现金/股票/房产/车/房贷/工资/日常/结转）。
3. 在「交易类型」管理里添加你的分类（种子为空，必须自己加，否则预算/热力图无意义）。
4. 在「币种与汇率」里维护汇率（默认已含 CNY/USD/EUR/GBP/JPY/HKD）。
5. 用「记一笔」命令或 `fin-beancount` 块开始记账。
6. 在笔记里插入 7 个视图块之一看数据（见 `03-view-blocks.md`）。

## 关键不变量 / 铁律

- **单一账本文件、单一 fin-beancount 块**：每笔都追加进这一个块的底部，不按月切片、不新建块。
- **账本只追加**：误入账需手动改 `账本.md`（或用 finance-log 的 id 定位删除那笔）。
- **资产价值 = 记账驱动**：别在配置里手填金额（曾有过"具体资产面板"，已废弃）。
