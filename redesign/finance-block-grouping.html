原型说明：这是「复式分录 · 已入账」状态加入时间聚合后的呈现探索（聚合开关仅用于已入账态，草稿态不加）。顶部新增一个分组分段控件 （每笔 / 按天 / 按周 / 按月 / 自定义），点击即可实时切换。分组模式下，每段时间被收拢成一个可展开的组： 组头显示该时段标签 + 该时段收支净额/笔数，默认折叠，点组头展开看明细。下方用 14 笔跨 5/6/7 三个月的样例数据演示。
「自定义」= 自定义 bucketing 粒度：选「每 N 天一组」，并可选起始日（默认 = 本账本最早一笔交易日，可改为任意一天）。 以起始日为锚，向前/向后按 N 天切等长组；若起始日选在中间，其之前那段交易日会自然并入相邻组、向后顺延。可在输入框直接填 N 或点快捷档（7天/10天/半月/月/季）。
顶部简易统计已移除：分组后每段自带组小计，整体合计不再重复展示。
